# /report - 일일 작업 레포트 생성

범용 일일 작업 레포트를 생성합니다. 현재 TODO 상태를 기반으로 작업 내용을 정리합니다.

**Critical Language Requirement**: You MUST respond in Korean at all times.

---

## 명령어 사용법

```
/report 

```

**저장 경로**: `Document/Reports/{프로젝트명}/Daily_Report_{날짜}.md`

---

## 레포트 생성 프로세스

### 1. 즉시 자동 생성

사용자 확인 없이 즉시 레포트를 생성합니다.

## 3. 정보 수집 방법

### 프로젝트 정보 (자동 + 추론)
1. **전체 프로젝트**: 프로젝트명 + 현재 컨텍스트에서 추론
2. **현재 단계**: TODO나 문서에서 "Alpha", "Beta", "MVP" 등 키워드 추출
3. **목표**: 프로젝트 계획 문서(Document/plan/*.md)나 대화 컨텍스트에서 추출

### Git 브랜치 (자동)
```bash
git branch --show-current
```

### TODO 정보 (자동)
- TodoWrite 도구의 현재 상태 활용
- completed, in_progress, pending 개수 계산

### 완료된 작업 (자동)

**우선순위 1: TODO가 있는 경우**
- completed 상태의 TODO에서 생성/수정된 파일 추출
- TODO 제목과 내용 기반으로 작업 내용 정리

**우선순위 2: TODO가 없는 경우**
- `git diff HEAD` 명령으로 스테이징된 변경사항 확인
- `git status` 로 새 파일(untracked) 확인
- 변경된 파일 목록 + 변경 내용(추가/수정/삭제 라인 수) 분석
- 파일 경로와 변경 내용에서 작업 성격 추론
  - 예: `Source/**/*.h` → "헤더 파일 작성"
  - 예: `Document/**/*.md` → "문서 작성"
  - 예: `*.cpp` 변경 → "구현 작업"

### 학습 내용 (자동 추론)
현재 대화 컨텍스트에서 학습한 개념 자동 추출:
- 새로 배운 클래스/개념
- 질문-답변 내용
- 작성한 코드에서 사용된 주요 패턴

## 4. 저장 및 확인

1. **즉시 생성**: `{경로}/Daily_Report_{YYYY-MM-DD}.md`
2. **완료 메시지**:
   ```
   ✅ 일일 레포트가 생성되었습니다!

   📄 파일: {전체 경로}
   📊 TODO: {완료수}/{전체수} 완료
   ```

---

## 5. 오류 처리

### TODO가 없는 경우
- ⚠️ 경고 표시하지 않음
- Git diff/status로 자동 전환하여 작업 내용 분석
- 레포트 "전체 TODO 현황" 섹션에 "TODO 미사용" 명시

### Git 변경사항도 없는 경우
```
⚠️ 작업 내용을 찾을 수 없습니다.
- TODO가 없습니다
- Git 변경사항이 없습니다

레포트를 생성할 수 없습니다.
```

### 경로가 존재하지 않는 경우
- 자동으로 폴더 생성

### 이미 오늘 레포트가 있는 경우
- 기존 레포트 전체를 현재 상태로 덮어씁니다 (자동 업데이트)

---

## 주의사항

- **간결성**: 각 섹션은 핵심만 담아 간결하게 작성
- **자동화**: 가능한 모든 정보는 자동 수집
- **대화 최소화**: 필수 정보만 물어보고 나머지는 자동 처리
- **일관성**: 모든 프로젝트에서 동일한 템플릿 사용
