# 소켓(Socket) 완전 가이드

## 개요

이 가이드는 소켓 프로그래밍의 기초부터 고급 주제까지 체계적으로 다룹니다. 전공 서적 수준의 깊이 있는 설명과 함께 실용적인 예제를 제공합니다.

## 문서 구조

각 파일은 독립적으로 읽을 수 있지만, 순서대로 읽는 것을 권장합니다.

### Part 1: 기초 개념
- **01_introduction.md** - 소켓의 정의, 역사, 필요성
- **02_socket_types.md** - 도메인별, 타입별 분류 및 상세 설명

### Part 2: 핵심 프로토콜
- **03_tcp_basics.md** - TCP 소켓의 동작 원리와 주요 함수
- **04_udp_basics.md** - UDP 소켓의 특징과 사용법

### Part 3: 고급 기능
- **05_socket_options.md** - 소켓 옵션 상세 설명
- **06_io_multiplexing.md** - 논블로킹과 멀티플렉싱 (select, poll, epoll)
- **07_advanced_topics.md** - 버퍼 관리, zero-copy, 멀티캐스트 등

### Part 4: 실전
- **08_tcp_state_machine.md** - TCP 상태 전이와 연결 관리
- **09_performance.md** - 성능 최적화 기법
- **10_error_handling.md** - 에러 처리 및 디버깅
- **11_debugging.md** - 디버깅 도구 사용법
- **12_best_practices.md** - 베스트 프랙티스와 일반적인 실수

### Part 5: 예제와 참고자료
- **13_examples.md** - 실전 예제 코드
- **14_references.md** - 참고 문헌 및 학습 자료

## 학습 방법

### 고급자
1. 필요한 섹션 참조
2. 성능 최적화 및 디버깅 기법 활용
3. 오픈소스 프로젝트 분석

## 주요 특징

- ✅ **개념 중심 설명**: 단순한 API 나열이 아닌 "왜"와 "어떻게"를 설명
- ✅ **실전 예제**: 동작하는 완전한 코드 제공
- ✅ **문제 해결**: 일반적인 실수와 해결 방법
- ✅ **깊이 있는 분석**: 내부 동작 원리까지 다룸
- ✅ **최신 기술**: epoll, zero-copy 등 현대적 기법 포함

## 사전 지식

이 가이드를 효과적으로 활용하려면 다음 지식이 필요합니다:

- C 언어 기초 (포인터, 구조체, 시스템 콜)
- 기본적인 네트워크 개념 (IP 주소, 포트)
- Linux/Unix 환경 (선택사항이지만 권장)

## 환경 설정

### Linux/macOS
대부분의 예제가 그대로 동작합니다.

```bash
gcc -o server server.c
./server
```

### Windows
Winsock API를 사용해야 하므로 일부 코드 수정이 필요합니다.
